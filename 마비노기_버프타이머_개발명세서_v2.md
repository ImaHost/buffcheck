# 마비노기 버프 타이머 알림 프로그램 — 개발 명세서 v2
### (Electron + React 프론트 / Python 백엔드)

이 파일 하나만으로 전체 구현이 가능하도록 아키텍처, 폴더 구조, DB 스키마,
프로세스 간 통신 방식, 코드 스켈레톤, 구현 순서까지 포함합니다.

---

## 1. 요구사항 요약

- 프론트: **Electron + React** (반투명 오버레이 창 포함, 배포 가능한 프로그램 형태)
- 백엔드: **Python** (화면 캡처, 이미지 처리, 아이콘 매칭, OCR, 상태 관리)
- 아이콘 DB: 미리 등록해둔 버프 아이콘과 매칭 (폴더 + DB 파일 필요)
- 동작 흐름:
  1. 앱 실행 → **F8** 입력 시 화면 캡처 오버레이가 뜸
  2. 사용자가 **버프창 전체 영역을 드래그**로 지정 (줄 단위 아님, 전체 패널 한 번만)
  3. 감시 시작 → 지정 영역 내에서 아이콘 자동 탐지 + 매칭 → 시간만 OCR로 읽음
  4. 반투명 오버레이 창이 게임 위에 떠서, 갱신 필요(30초 이하) 버프를 실시간 표시

## 4. DB 스키마 (SQLite: `icons.db`)

```sql
CREATE TABLE buffs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,        -- 버프 이름 (파일명에서 추출)
    icon_path TEXT NOT NULL,          -- buff_icons/ 내 상대경로
    icon_width INTEGER NOT NULL,
    icon_height INTEGER NOT NULL,
    time_offset_x INTEGER DEFAULT 24, -- 아이콘 기준 시간텍스트 x 오프셋 (보정값)
    time_offset_y INTEGER DEFAULT 0,
    time_width INTEGER DEFAULT 50,
    time_height INTEGER DEFAULT 20,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);
```

- `time_offset_*` 값은 모든 버프가 보통 동일한 UI 레이아웃을 쓰므로 **공통 기본값** 하나로 시작해서,
  실제 게임에서 어긋나면 개별 버프별로 미세 조정하는 구조입니다.
- 아이콘 자체(`icon_path`)는 템플릿 매칭에 원본 이미지를 그대로 사용하므로 pHash 캐시는 불필요합니다 (v1과 차이점).

```python
# backend/db.py
import sqlite3

DB_PATH = "icons.db"

def get_connection():
    return sqlite3.connect(DB_PATH)

def init_db():
    conn = get_connection()
    conn.execute("""
        CREATE TABLE IF NOT EXISTS buffs (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT UNIQUE NOT NULL,
            icon_path TEXT NOT NULL,
            icon_width INTEGER NOT NULL,
            icon_height INTEGER NOT NULL,
            time_offset_x INTEGER DEFAULT 24,
            time_offset_y INTEGER DEFAULT 0,
            time_width INTEGER DEFAULT 50,
            time_height INTEGER DEFAULT 20,
            created_at TEXT DEFAULT CURRENT_TIMESTAMP
        )
    """)
    conn.commit()
    conn.close()

def get_all_buffs():
    conn = get_connection()
    conn.row_factory = sqlite3.Row
    rows = conn.execute("SELECT * FROM buffs").fetchall()
    conn.close()
    return [dict(r) for r in rows]

def upsert_buff(name, icon_path, w, h):
    conn = get_connection()
    conn.execute("""
        INSERT INTO buffs (name, icon_path, icon_width, icon_height)
        VALUES (?, ?, ?, ?)
        ON CONFLICT(name) DO UPDATE SET
            icon_path=excluded.icon_path,
            icon_width=excluded.icon_width,
            icon_height=excluded.icon_height
    """, (name, icon_path, w, h))
    conn.commit()
    conn.close()
```

```python
# backend/build_icon_db.py
import os
import cv2
from db import init_db, upsert_buff

ICON_DIR = "../buff_icons"

def main():
    init_db()
    count = 0
    for fname in os.listdir(ICON_DIR):
        if not fname.lower().endswith(".png"):
            continue
        name = os.path.splitext(fname)[0]
        path = os.path.join(ICON_DIR, fname)
        img = cv2.imread(path)
        h, w = img.shape[:2]
        upsert_buff(name, fname, w, h)
        count += 1
    print(f"{count}개 아이콘 등록 완료 → icons.db")

if __name__ == "__main__":
    main()
```

## 5. 아이콘 매칭 — 템플릿 매칭 방식 (v1의 pHash 대체)

전체 패널 영역 안에서 각 아이콘이 "어디 있는지"까지 한 번에 찾아야 하므로,
개별 슬롯을 잘라서 비교하는 pHash 대신 **`cv2.matchTemplate`**을 사용합니다.

```python
# backend/icon_matcher.py
import cv2
import numpy as np

MATCH_THRESHOLD = 0.85  # 0~1, 높을수록 엄격 (0.8~0.9 권장, 실측 후 조정)

def find_all_icons(panel_img: np.ndarray, buff_db: list[dict], icon_dir: str):
    """
    panel_img: F8로 지정한 버프 패널 전체 캡처 이미지
    buff_db: db.get_all_buffs() 결과
    반환: [{"name": str, "x": int, "y": int, "w": int, "h": int}, ...]
          (패널 이미지 기준 상대 좌표)
    """
    results = []
    panel_gray = cv2.cvtColor(panel_img, cv2.COLOR_BGR2GRAY)

    for buff in buff_db:
        template = cv2.imread(f"{icon_dir}/{buff['icon_path']}", cv2.IMREAD_GRAYSCALE)
        if template is None:
            continue

        res = cv2.matchTemplate(panel_gray, template, cv2.TM_CCOEFF_NORMED)
        locations = np.where(res >= MATCH_THRESHOLD)

        for pt in zip(*locations[::-1]):  # (x, y)
            results.append({
                "name": buff["name"],
                "x": pt[0],
                "y": pt[1],
                "w": buff["icon_width"],
                "h": buff["icon_height"],
                "time_offset_x": buff["time_offset_x"],
                "time_offset_y": buff["time_offset_y"],
                "time_width": buff["time_width"],
                "time_height": buff["time_height"],
            })

    return _remove_duplicate_matches(results)


def _remove_duplicate_matches(results, min_distance=10):
    """같은 위치 근처에서 중복 매칭된 결과 제거 (Non-Maximum Suppression 간소화 버전)"""
    filtered = []
    for r in results:
        duplicate = False
        for f in filtered:
            if abs(r["x"] - f["x"]) < min_distance and abs(r["y"] - f["y"]) < min_distance:
                duplicate = True
                break
        if not duplicate:
            filtered.append(r)
    return filtered
```

**장점**: 버프 개수/순서가 실시간으로 바뀌어도 줄 번호 관리 없이 매 프레임 자동으로 위치까지 파악됩니다.
**주의**: 아이콘이 서로 매우 비슷하게 생긴 경우 `MATCH_THRESHOLD`를 높여야 오매칭이 줄어듭니다.

import { useState } from 'react';

export default function CaptureOverlay() {

      onMouseDown={handleMouseDown}
      onMouseMove={handleMouseMove}

        <div style={{
          position: 'absolute',
          left: rect.x, top: rect.y, width: rect.width, height: rect.height,

## 8. Electron ↔ Python 통신 (pyBridge.js)

stdout에 **1줄 = 1개의 JSON**을 출력하는 방식이 가장 단순하고 안정적입니다 (별도 서버/포트 불필요).

```javascript
// electron/pyBridge.js
const { spawn } = require('child_process');
const readline = require('readline');

let pyProcess = null;

function startPythonBackend(onData) {
  pyProcess = spawn('python', ['backend/main.py'], { cwd: __dirname + '/..' });

  const rl = readline.createInterface({ input: pyProcess.stdout });
  rl.on('line', (line) => {
    try {
      const data = JSON.parse(line);
      onData(data);
    } catch (e) {
      console.error('Python 출력 파싱 실패:', line);
    }
  });

  pyProcess.stderr.on('data', (data) => console.error('Python stderr:', data.toString()));
}

function sendCommand(cmd) {
  if (pyProcess) pyProcess.stdin.write(JSON.stringify(cmd) + '\n');
}

module.exports = { startPythonBackend, sendCommand };
```

```python
# backend/main.py
import sys
import json
import threading
import time
import mss
import numpy as np

from db import get_all_buffs
from icon_matcher import find_all_icons
from color_mask import preprocess_for_ocr
from time_ocr import read_time_from_region
from buff_state import BuffTimer

CAPTURE_INTERVAL = 0.3
ICON_DIR = "../buff_icons"

state = {"region": None, "running": False}
active_buffs: dict[str, BuffTimer] = {}

def listen_commands():
    """stdin에서 Electron이 보낸 명령(JSON) 수신"""
    for line in sys.stdin:
        try:
            cmd = json.loads(line)
        except json.JSONDecodeError:
            continue
        if cmd.get("type") == "set_region":
            state["region"] = {
                "x": cmd["x"], "y": cmd["y"],
                "width": cmd["width"], "height": cmd["height"]
            }
            state["running"] = True

def emit(data: dict):
    print(json.dumps(data), flush=True)

def main_loop():
    buff_db = get_all_buffs()
    with mss.mss() as sct:
        while True:
            if not state["running"] or state["region"] is None:
                time.sleep(0.5)
                continue

            r = state["region"]
            shot = sct.grab({"left": r["x"], "top": r["y"], "width": r["width"], "height": r["height"]})
            panel_img = np.array(shot)[:, :, :3]

            matches = find_all_icons(panel_img, buff_db, ICON_DIR)
            seen = set()

            for m in matches:
                time_x = m["x"] + m["time_offset_x"]
                time_y = m["y"] + m["time_offset_y"]
                time_crop = panel_img[time_y:time_y + m["time_height"], time_x:time_x + m["time_width"]]

                remaining = read_time_from_region(time_crop)
                if remaining is None:
                    continue

                seen.add(m["name"])
                if m["name"] not in active_buffs:
                    active_buffs[m["name"]] = BuffTimer(m["name"], remaining)
                else:
                    active_buffs[m["name"]].apply_ocr_reading(remaining)

            for name in list(active_buffs.keys()):
                if name not in seen:
                    del active_buffs[name]
                    continue
                active_buffs[name].tick()

            emit({
                "buffs": [
                    {"name": t.name, "remaining": t.remaining}
                    for t in active_buffs.values()
                ]
            })

            time.sleep(CAPTURE_INTERVAL)

if __name__ == "__main__":
    threading.Thread(target=listen_commands, daemon=True).start()
    main_loop()
```

> `time_ocr.py`는 기존 명세서(v1)의 `read_time()`과 동일 로직이며, 함수명만 `read_time_from_region`으로 통일했습니다.
> `color_mask.py`, `buff_state.py`는 v1과 동일하게 사용합니다.

## 9. 구현 순서

### 9-1단계: Python 백엔드 단독 완성 (Electron 없이)
- `db.py`, `build_icon_db.py`로 `icons.db` 생성 확인
- `buff_icons/`에 아이콘 몇 개 등록 후 `icon_matcher.py`의 `find_all_icons()`가 좌표를 정확히 찾는지 **스크립트로 단독 테스트**
- `time_ocr.py`가 아이콘 위치 기준 오프셋으로 시간 텍스트를 정확히 읽는지 확인 (오프셋 값 보정 포함)
- 완료 기준: 고정 이미지 파일(테스트용 스크린샷)로 아이콘+시간 매칭이 100% 정확

### 9-2단계: Electron 기본 창 + Python 프로세스 연동
- `pyBridge.js`로 Python 프로세스 실행 및 stdout JSON 수신 확인 (콘솔 로그로만 확인, UI 아직 없음)
- 완료 기준: `main.py` 실행 후 임의 좌표(`set_region` 하드코딩)로 5초 이상 정상적으로 JSON이 계속 출력됨

### 9-3단계: F8 영역 선택 오버레이
- `CaptureOverlay.jsx` + `main.js`의 globalShortcut 연동
- 완료 기준: F8 누르면 오버레이가 뜨고, 드래그 후 좌표가 Python `set_region`으로 정확히 전달됨 (Python 쪽 로그로 확인)

### 9-4단계: 알림 오버레이 완성
- `NotifyOverlay.jsx` 연동, `setIgnoreMouseEvents` 적용
- 완료 기준: 실제 게임에서 F8로 영역 지정 후 버프 발동 시 30초 이하로 진입하면 오버레이에 표시됨

### 9-5단계: 다중 버프 + 장시간 안정성 검증
- 버프 여러 개 동시 발동, 30분 이상 장시간 실행
- CPU/메모리 누수 여부 확인

## 10. 배포 (참고)

- Python 백엔드는 `pyinstaller --onefile backend/main.py`로 exe화 후 Electron 앱 리소스에 포함
- `pyBridge.js`의 `spawn('python', ...)` 부분을 배포 시 `spawn(path.join(process.resourcesPath, 'main.exe'))`로 교체
- `electron-builder`로 최종 패키징 (Windows 대상이면 `nsis` 타겟)

## 12. 트러블슈팅 (추가분)

| 증상 | 원인 가능성 | 확인할 파일 |
|---|---|---|
| F8 눌러도 오버레이 안 뜸 | globalShortcut 등록 실패(다른 프로그램과 충돌) | `main.js`의 `globalShortcut.register` 반환값 확인 |
| 영역 지정했는데 Python이 반응 없음 | stdin 전달 타이밍 문제, JSON 파싱 실패 | `pyBridge.js`의 `sendCommand`, `main.py`의 `listen_commands` 로그 확인 |
| 아이콘은 찾는데 시간 텍스트가 계속 다른 위치를 읽음 | `time_offset_x/y`가 실제 UI와 안 맞음 | `icons.db`의 offset 값을 해당 버프만 개별 수정 |
| 같은 아이콘인데 2번 감지됨 (중복 알림) | NMS 로직의 `min_distance`가 너무 작음 | `icon_matcher.py`의 `_remove_duplicate_matches` 파라미터 조정 |
| 알림창이 게임 클릭을 막음 | `setIgnoreMouseEvents` 미적용 | `main.js`의 `createNotifyOverlay` 확인 |
